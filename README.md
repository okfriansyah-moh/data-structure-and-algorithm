## Getting Started

### Prerequisites
- Java 8 or higher
- Maven (for building)

### Building
```bash
mvn clean compile
```

### Running Tests
```bash
mvn test
```

## Learning Path Recommendation

### Beginner
1. Start with **Arrays** - understand basic data structures
2. Learn **Recursion** - fundamental concept
3. Study **Sorting** - bubble, selection, insertion sort
4. Explore **Searching** - linear and binary search

### Intermediate
1. Master **Linked Lists** - singly and doubly
2. Learn **Stacks & Queues** - important patterns
3. Study **Hash Tables** - fast lookups
4. Practice **Array Problems** - LeetCode style

### Advanced
1. Learn **Trees** - BST and traversals
2. Study **Graphs** - BFS, DFS, algorithms
3. Master **Dynamic Programming** - optimization
4. Solve complex problems - combine multiple concepts
